YOUR HISAB / HISAB KITAB — Version 2.1

INSTALL ON ANDROID (Chrome):
1. Extract this ZIP.
2. Upload index.html, manifest.json and sw.js together to one folder on Netlify (or GitHub Pages).
3. Open the HTTPS site in Chrome.
4. Chrome menu (⋮) > Install app / Add to Home screen.

USING THE APP:
- Create one separate account for each customer or work location.
- New accounts include default motor types and rates:
  0.5, 1, 2, 3, 5 HP TP = ₹50 each
  7.5 HP TP = ₹80; 10 HP TP = ₹100
  0.5, 1, 2, 3 HP SP = ₹70 each
- Change any default rate in Settings. Each new entry starts with that motor's current default rate; you can also change the rate for an individual entry.
- Add daily entries, edit/delete entries, view the calendar, date-range reports, motor-wise totals, download CSV, or print/save PDF.
- Choose English, Hindi or Gujarati.
- Use Settings > Backup data regularly. Restore a JSON backup if needed.

IMPORTANT DATA NOTE:
Data is saved locally in this browser on this device. There is no automatic cloud sync or multi-device sharing. Back up regularly. Clearing browser data can erase app records.
- App starts with zero accounts and zero transactions; no sample customer data is included.
